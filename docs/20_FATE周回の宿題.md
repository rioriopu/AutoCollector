## 1. 飛び方と入り方を人に寄せる（2026-09-25 依頼）

### いまの動き

FATE の**真上まで飛んで、そこから真下へ降りる**。

```
        ┌─┐
        │ │  真上から急降下
  ──────┴─┴──────
       FATE
```

実装は `MountService.LiftForFlight` で目的地を 30m 持ち上げ、
真上へ着いたら降りるようにしてある（`FateRunner.TickMoving`）。
起伏に触れて飛行が解けるのを避けるための措置だった。

### 望まれている動き

> 一般的には FATE の中央真ん中付近の上空まで飛んで、そこから急降下して
> 参加なんてしません。FATE に対して一直線に進み、最大高度〜地上の間
> くらいの高度で飛び、FATE には真上上空からではなく、FATE 範囲地上に
> 対して、横から飛び込む感じで入ります。

```
   ＼
     ＼  一直線に、ほどほどの高度で
       ＼
  ────────＼────
          FATE   ← 横から滑り込む
```

要点は 3 つ。

1. **一直線に進む**（真上へ上がってから水平移動、ではない）
2. **高度はほどほど**（最大高度と地上の中間あたり。真上に張り付かない）
3. **横から入る**（真上から降りるのではなく、斜めに滑り込む）

### 実装の当て

- 目的地を真上へ持ち上げるのをやめ、**FATE の手前**に降下の目標を置く。
  中心から見て、自分が飛んできた向きの外周あたり。
  そこを目的地にすれば、経路は自然に斜めの直線になる。
- 高度は「持ち上げ量」ではなく**経路の途中での高さ**で考える。
  vnavmesh は 3D 経路を引くので、出発点を上げれば経路全体が上がる。
  離陸後の上昇時間（`ClimbDuration`）で調整できる可能性がある。
- 降下は FATE の円へ入る前から始める。円に入った時点で
  地上付近にいるのが理想。

### 気をつけること

**起伏に触れて飛行が解ける問題が戻ってこないようにする。**
これを避けるために真上へ上げた経緯がある（2026-09-25 のコミット）。
高度を下げるなら、経路が地面を擦らないことを別の方法で担保する。

`AutoFateGrind/Core/Tasks/AutoCommon.Landing.cs` に、着地点の探し方が
ある（真下の床を探す・周囲 6m の輪で候補を作る）。降りる場所を
決める部分はそのまま参考にできる。

## 2. 実機で確かめたい数値

| 値 | いま | 見るところ |
|---|---|---|
| `MountService.FlightLift` | 30m | 低いと起伏に触れる。高いと真上で長く降りる |
| `MountService.ClimbDuration` | 2.5 秒 | 短いと経路が地表寄りになる |
| `MountService.MinDistanceToMount` | 20m | 短距離で乗り降りを繰り返さないか |
| `Config.FatePrefetchPct` | 70% | 次の FATE を決め始める達成度 |

## 3. まだ作っていない機能

1. **ギサールの野菜の購入**
   残量の検知と召喚はある。買いに行く部分が無い。
   窓口は確定済み: バンゴ・ザンゴ / ENpcResident **1001787** /
   territory **129**（リムサ下層）/ X=-62.1 Y=18.0 Z=9.4

2. **ベンチャー回収のための帰還**
   デジョン（リキャスト中はテレポート）でホームタウンへ戻る。

3. **バイカラージェムの交換そのもの**
   周回して貯めるところまでは動く。交換の窓口へ行く経路が無い。
   `ExchangeResolver` はベリルへ到達できない（ベリルの CustomTalk 724 は
   Script も SpecialLinks も空で、SpecialShop へ届かない）。
   `FateTokenService` が `FateShop` から窓口を引けるので、
   そこを `ExchangeResolver` へ繋ぐ必要がある。

## 4. 参考にできるもの

`C:\ソース\FF14-FATE調査_20260922_185922\sources\` に 19 リポジトリある。
FATE 周回と移動について、特に読む価値があるもの:

| ファイル | 内容 |
|---|---|
| `XeldarAlz__FFXIV-AutoFATEGrind/.../AutoCommon.Landing.cs` | **着地**。空中からの降り方、着地点の探し方 |
| 同 `AutoFate.Movement.cs` | FATE への移動 |
| 同 `AutoFate.Engage.cs` | 戦闘の開始と維持 |
| 同 `AutoCommon.Teleport.cs` | テレポートの作法 |

Landing.cs には実測に基づく知見が書かれている。

- 上空でそのまま降りると、最寄りのメッシュ点（壁の縁や丘の上）へ
  飛んでしまう。先に真下の床を探してそこへ降りる
- 空中でジャンプすると、ゲーム自身の降下が終わる。これをやらないと
  降下が続き、それがプレイヤー入力として vnavmesh に読まれ、
  次の経路を積んだ瞬間に捨てられる
