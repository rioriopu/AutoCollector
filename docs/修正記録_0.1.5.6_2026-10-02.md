# AutoCollector v0.1.5.6 修正記録

対象: このPCの AutoCollector。基点は `integration/all-v2` の `728449683b395890c531d2be65135c096e097938`（v0.1.5.5）。
作業場所は `C:\ソース\AutoCollector`、ブランチは `fix/fate-currency-20261002`。
旧ローカルブランチ `feat/bicolor-shop-map` はそのまま残した。GitHub・相手PCへの書き込みは行っていない。

## 修正内容

### バイカラージェム交換後の復帰

- AutoDuty が動いていないだけで終了していた早期 return を削除。既存の Artisan → AutoRetainer 抑制 → F.A.T.E → AutoDuty の中断順を維持し、復帰は F.A.T.E → AutoDuty の順に進める。
- 交換失敗時も、中断した周回の記録を残して復帰処理へ進める。結果未確認の購入記録は消さず、自動再購入を防ぐ。
- 明示的な停止では再開しない。復帰にも上限時間を設け、元の失敗理由を保持する。
- 交換全体のタイムアウトが復帰処理を繰り返し中断する経路を修正。
- 動いていなかった F.A.T.E の中断記録が、失敗後に次の交換へ残らないようにした。
- 製作目標の実行器が F.A.T.E 用プリセットを拾わないようにした。

### 開始NPCとフォーローン

- 準備中（Preparing）の F.A.T.E も候補とし、到着後に開始役へ接近する。
- クライアントの `FateContext.MotivationNpc` を **EntityId（個体ID）** として照合。旧修正の BaseId 比較・EventNpc 限定を撤廃。出典の不確かな外部NPC名一覧は使わない。
- NPCへ3mを目安に接近し、ターゲットを合わせただけでは声かけ済みにしない。実際の Interact 送信後に記録し、同じ出現で繰り返さない。
- 自分が開いた会話・確認だけを短い期限内で進める。敵出現・戦闘開始・対象変更時は会話を終了。開始を確認できない準備中F.A.T.Eは一時的に見送る。
- フォーローン（BNpcName 6738）・フォーローンメイデン（6737）を通常敵より優先。現在の通常ターゲットが生きていても切り替える。接近先の選択も同じ優先順。
- 別F.A.T.E、死亡・非ターゲット可能な敵、ハーム・フォーローン（12349）は優先対象に含めない。

### 特殊通貨表

- ログイン後に取得し、5秒間隔で更新を確認。空の取得結果では最後の有効な表を捨てない。ログアウトではキャラクター由来の表を破棄する。
- 交換・納品の実行中は対応表の差し替えを遅らせる。
- 有効な対応が変わったとき、収集品報酬、製作計画、製作／採集の分類、交換索引、交換画面の一覧と検索キャッシュを更新。
- 同梱表の index 1 を詩学（28）からクラフター白貨（25199）へ修正。版なしの旧通貨表もバックアップして更新する。
- 納品失敗時の上限判定は、その収集品が生む通貨だけを見る。詩学が上限でも、無関係な紫貨の収集品を飛ばさない。
- 通貨一覧の重複を除外。系統・種別は表更新時に名前・ショップIDで選択を引き継ぐ。
- 製作／採集の両方に分類される通貨の警告を、同じ通貨について毎フレーム出さない。

### 関連修正

- F.A.T.E プリセットの開始ボタンは F.A.T.E を開始し、AutoDutyへ送らない。
- 採集の自動開始が未実装であることを開始操作の場所に表示。
- F.A.T.Eが動いていない状態で止めたとき、vnavmesh全体への無条件の停止要求を抑止。
- NPC・敵への接近先も停止後の経路監視に使い、停止処理の前に行き先を保存。
- 戦闘不能時は使用できないデジョンを連打せず、DeathScreenの帰還操作を3秒間隔で試す。レイズ待ち時間切れログも間引く。
- テレポ要求が受理された後に詠唱が中断された場合、詠唱中・Lifestream動作中でなければ待機後に再試行する。

## ゲーム内での確認

2026-10-02の保存済みDalamud設定は `C:\DevPlugins\AutoCollector\AutoCollector.dll` を有効にしている。
旧メモにあったネットワーク先とは異なる。既に起動している各ゲームがメモリ内でどのDLLを動かしているかまでは、この確認では確定していない。

1. 動作中なら停止し、AutoCollectorを読み込み直す。ゲームを2つ起動している場合は両方。画面の版が **0.1.5.6** になったことを確認する。
2. F.A.T.Eのマップとバイカラージェムの交換プリセットを有効にし、F.A.T.E → 交換 → 元のマップで周回再開を確認する。ログの「FATE 周回を再開します」を見る。
3. 交換先に到達できない場合などでも、復帰または復帰失敗の表示が残ることを確認する。明示停止した場合は再開しないことも確認する。
4. 開始役のいる準備中F.A.T.Eで、接近 → 対話 → 開始を確認する。ログの「開始 NPC に声をかけました」を見る。
5. 通常敵を攻撃中にフォーローンが出現したとき、ターゲットが切り替わることを確認する。
6. ログイン前から読み込んだ状態でログインし、通貨表更新ログ・通貨一覧・紫貨／橙貨の納品を確認する。

**ゲーム内の実機動作は未検証。** とくにNPC会話の種類、移動経路、DeathScreenの実反応、複数クライアントでの再読み込みは実機確認が残る。
クライアントが開始NPCの個体IDを提供しないF.A.T.Eでは、名前を推測して別NPCへ話しかけず、開始待ちの期限後に見送る。

今回の修正は採集自動化の新規実装ではない。元メモにある廃止済みトームストーンの全整理、HQ要求の扱い等の機能全体を検証済みとするものでもない。
