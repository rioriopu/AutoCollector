# リリース告知テンプレート

配布リポジトリへリリースを出したら、Discord へ告知する。
書式は下記に固定する。プラグイン名・バージョン・更新履歴以外は変えない。

## テンプレート

````markdown
### AutoCollector v n.n.n.x リリース致しました。

### 更新履歴: 

◆共通

- 

- 



配布リポジトリ



```

https://raw.githubusercontent.com/rioriopu/PrivateReleaseRepo/main/repo.json

```
````

## 書くときの決まり

- バージョンは `AutoCollector.csproj` の `<Version>` と揃える。
  配布リポジトリの `repo.json` の `AssemblyVersion` とも一致していること。
- `◆共通` は既定の見出し。対象が分かれる場合は `◆AutoDuty 連携` のように節を足してよい。
- 各項目は利用者から見た変化を 1 行で書く。内部の実装名やクラス名は書かない。
  - 良い例: 「AutoDuty を手動で止めたときに、勝手に周回が再開されないようにしました」
  - 悪い例: 「AutoDutyKeeper に LooksLikeLoopCompletion を追加」
- 不具合修正は「何が起きていたか」から書く。直した内容だけを書かない。
  - 良い例: 「周回がすべて終わるまで交換に行かなかった問題を修正しました」
- 設定を追加・削除した場合は、利用者が何をすればよいかを書く。
- 既定値を変えた場合は、既存の設定がどうなるかを書く。

## 出す前に確認すること

- リリースの zip がダウンロードできること
- `repo.json` の `AssemblyVersion` と `DownloadLinkInstall` のタグが新しいものになっていること
- `IconUrl` が 200 を返すこと
