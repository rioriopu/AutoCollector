# Auto Collector できること・仕様

版: **0.1.4.2**（2026-09-26 時点 / コミット 39bc8be）
対象: Dalamud プラグイン（DalamudApiLevel 15）

この資料は**ソースを読んで確認した内容**で書いてある。
未実装のもの、確認できなかったものは、そのように明記した。

---

## 1. このプラグインは何をするものか

ひとことで言うと **「通貨が貯まったら、自動で交換所へ行って交換する」**。

そこから派生して、次の機能を持つ。

| 機能 | 何をするか |
|---|---|
| **自動交換** | 通貨が閾値に届いたら、走っている自動処理を安全に止め、交換所へ移動して交換し、元の処理へ戻す |
| **FATE 自動周回** | FATE を探して移動・戦闘・離脱を繰り返す。バイカラージェムなどを稼ぐ |
| **収集品の納品** | 収集品を納品所へ持って行き、スクリップに換える |
| **製作して稼ぐ** | スクリップが足りないぶんを、収集品を作って納品して賄う |
| **リテイナーからの取り出し** | 製作の素材をリテイナーから引き出す |

---

## 2. 必要なもの・連携するもの

### 必須ではないが、機能ごとに要るもの

| プラグイン | 使いどころ | 無いとどうなるか |
|---|---|---|
| **vnavmesh** | 移動全般 | FATE 周回が使えない。交換所への自動移動も不可 |
| **BossMod Reborn** | FATE の戦闘 | FATE 周回が使えない |
| **Lifestream** | テレポート | マップ間の移動ができない |
| **AutoDuty** | 周回の中断・再開 | 連携しないだけ。交換自体は動く |
| **AutoRetainer** | リテイナー・ベンチャー | 取り出し機能が使えない |
| **Artisan** | 製作 | 製作して稼ぐ機能が使えない |

FATE 周回だけは **vnavmesh と BossMod Reborn の両方が必須**
（`FateRunner.IsUsable`）。片方でも欠けていると、稼ぎ方の一覧にも出ない。

## 4. 自動交換（中核機能）

### 4-1. 大前提：周回への相乗りとして動く

**プリセットを有効にしただけでは動かない。**
既定では **AutoDuty か Artisan が動いているときだけ**自動交換する
（設定「AutoDuty や Artisan が動作しているときだけ自動交換する」既定 ON）。

手で押す「行って交換」は、この設定に関わらず実行できる。

### 4-2. プリセットで設定できること

| 項目 | 既定 | 意味 |
|---|---|---|
| 名前 | 新しいプリセット | |
| 有効／無効 | 無効 | |
| **監視する通貨** | 数理（スロット 2） | トームストーンは**スロット番号**で保存するため、パッチで中身が入れ替わっても追従する |
| **交換リスト** | 空 | 複数の品を並べられる。上から順に交換 |
| 交換所 NPC | 自動選択 | 窓口を固定したいとき |
| **閾値** | 上限の 90% | 交換を始める条件（次項） |
| **どこまで交換するか** | 指定量の通貨を残すまで | （次々項） |
| 残す通貨量 | 500 | 「指定量の通貨を残すまで」のとき |
| 個数・回数 | 1 | 「指定回数だけ」などのとき |
| 製作して稼ぐ | OFF | 第 6 章 |
| 残す鞄の空き枠 | 10 | **製作用**。交換の関門ではない |

**交換リストの 1 行**には「交換する個数」と「所持数の上限」がある。
所持数の上限は**「持っていたら飛ばす」の二択ではない**。
上限 5 で 3 個持っていれば、足りない 2 個だけを交換する。

**交換対象の選び方**は、ゲーム内のアイテム交換画面と同じ
「系統 → 種別 → 品」の 3 段構成。名前での横断検索もある。
品は種別を開いたときに初めて読む（数千件を先読みすると固まるため）。

### 4-3. 閾値の 3 方式

| 方式 | 意味 | 発動条件 |
|---|---|---|
| 固定値 | その数に達したら | 所持数 ≧ 設定値 |
| **上限に対する割合**（推奨・既定） | 所持上限の N% に達したら | 所持数 ≧ 上限 × N/100 |
| 上限までの残り | 上限まであと N を切ったら | 所持数 ≧ 上限 − N |

**制約**: 割合と「上限までの残り」は、**所持上限が取れないと判定できない**。
取れない場合は交換しない（安全側に倒す）。

### 4-4. どこまで交換するか（4 種）

| モード | 動作 |
|---|---|
| **交換できる限り** | 通貨か所持枠が尽きるまで |
| **指定量の通貨を残すまで**（既定） | 設定した通貨量を割り込まない範囲で |
| **指定回数だけ** | 回数指定（1〜30） |
| **目標所持数に達するまで** | 報酬アイテムの所持数が目標に届くまで |

**重要な相互作用**

- 「目標所持数に達するまで」を選ぶと、**交換リストの行の「所持の上限」は見なくなる**。
  モードの目標が優先される
- **終わりを決める条件が 1 つも無いと交換しない。**
  「個数上限なし＋所持上限 0＋交換できる限り」の組み合わせは弾かれ、
  「個数・所持の上限・どこまで交換するか のいずれかを設定してください」と出る
  （ただし「製作して稼ぐ」を入れている場合は、素材が尽きるまでが正規なので通す）

### 4-5. 交換の実行と歯止め

| 歯止め | 値 | 理由 |
|---|---|---|
| 1 回の移動での交換回数 | **最大 30 回** | 交換は取り返しがつかないため、意図的に低く |
| 1 回の発火でまとめる個数 | 最大 20 個 | |
| **交換で残す鞄の空き枠** | **常に 2 枠**（固定） | AutoRetainer が空き 0 のキャラを対象外にするため |
| 交換 1 回ごとの間隔 | 1.2 秒 | 所持数の反映順序で誤判定しないため |

- **同じ窓口で扱える品だけをまとめて交換する。** 別窓口の品は次の判定で拾う
- 出発前に「行っても 1 回も交換できない」と分かる品は見送る
  （テレポートと周回の停止・再開を無駄に繰り返さないため）
- 交換の結果は**所持数の変化で検証**する。未確定のものは設定に記録され、
  **確定するまで新しい交換を受け付けない**（リロードやクラッシュを跨いで残る）

**自動無効化**: 同じプリセットで **2 回連続で失敗**すると、そのプリセットを
自動的に無効にして理由を残す。ただし**環境都合の失敗は数えない**
（中止・外部プラグインのエラー・鞄の空き不足・ショップが閉じた等）。

### 4-6. 対応している通貨

**アラガントームストーン** — `Tomestones` シートの全スロット。
ItemId ではなくスロット番号で保存するため、パッチで入れ替わっても追従する。
週上限のあるものは、今週の取得量と上限も追跡する。

**スクリップ** — クラフター／ギャザラーの紫貨・橙貨、詩学。
同梱の対応表とクライアントの実行時の値を**重ねて**使う。

実際に交換所の品のコストとして使われている通貨だけを一覧に出す
（白貨のような廃止済みは隠す）。
**選択中の通貨が一覧から消えても、黙って別の通貨に書き換えない。**

### 4-7. 交換候補の構築

ゲームデータから「この通貨で何がどこで買えるか」を作る。
ENpcBase が約 6 万行あるため、1 フレームあたりの処理量を抑えて少しずつ進める。

**利用者から見た制約**

- 通貨を選んだ直後は「交換候補を構築しています（進捗%）」になり、
  完成するまで交換は始まらない
- 索引は**1 通貨ぶんしか持てない**。別通貨のプリセットが並ぶと作りかけが捨てられる
- 手で押した交換は、完成を最大 60 秒待つ
- 構築に失敗すると 5 分のクールダウンが入る

## 5. 収集品の納品

手持ちの収集品をまとめて納品し、スクリップに換える。
**1 個ずつ撃って毎回確かめる**（まとめて撃つと何個成立したか分からなくなるため）。

### 自動で飛ばす・止める条件

| 条件 | 動作 |
|---|---|
| どのスクリップにも余裕がない | その場で終了 |
| 収集価値が納品の下限に届かない | その品を飛ばす |
| 納品するとスクリップが上限を超える | その品を飛ばす（全体は止めない） |
| 撃っても納品されなかった | 1 度だけ撃ち直し、駄目なら飛ばして続行 |
| **狙っていない収集品が減った** | **その場で停止**（取り違えの恐れ） |

品目ごとの報酬量はやってみるまで分からないため、**1 回目の納品で実測**し、
2 回目以降はその値で溢れるかを判断する。

### 行き先

「収集品納品窓口」をゲームデータから探す（NPC の番号は埋め込まない）。
扱うのは一般の納品窓口のほか、スカイスチール／リスプレンデント／モーエンの各ツール。

指定が無ければ**一般の納品窓口**から選び、いまいるエリア →
**アクセス済みエーテライトのあるエリア**の順で優先する。

### 納品と交換を交互に回す

```
収集品を納品 → スクリップが上限に近づいて停止
  → スクリップを使って交換 → 枠が空く
    → まだ収集品があれば納品へ戻る
```

止まらなくなるのを防ぐため、**納品する意味のある収集品だけを数える**。
「いま納品できる」と「交換すれば納品できる」を分けて扱う
（一緒にすると、納品へ行っては 1 個も納品できずに戻るループになる）。

一周して何も減っていない状態が 2 回続けば打ち切る。上限は 50 周。

**よくある詰まり**: そのスクリップを**減らす交換設定が無い**と、
そのスクリップを生む収集品は納品されない。その旨が画面に出る。

## 6. 製作して稼ぐ

プリセットに「製作して稼ぐ」を入れると、**欲しいアイテムが揃うまでを通しで回す**。

```
① 足りない素材をリテイナーから取り出す
② 鞄の空き枠まで収集品を作る
③ 納品する
④ スクリップが上限に達したら納品をやめる
⑤ スクリップを使って欲しいアイテムと交換する
   → まだ足りなければ ① へ戻る
```

### 判断の順番

1. 目標に届いた → 終わる
2. スクリップがもう足りている → 交換して終わらせる
3. 納品できる収集品を持っている → 納品と交換を回す
4. 素材が足りない → リテイナーから取り出す
5. 素材がある → 作る

順番には意味がある。2 を 3 より先に置かないと要らない収集品を作り続け、
3 を 5 より先に置かないと鞄が尽きる。

### Artisan との連携

**Artisan は必須**（無いと始められない）。

- **回数であって個数ではない。** 黒麦粉は 1 回で 3 個できるので、162 個なら 54 回
- **中間素材から先に作る**（素材切れで止まるため）
- 収集品は所持数を数えられないため、**鞄の枠を直接見て**終わりを判断する
- 「止める」を押したら耐久モードを直接落とす
  （停止要求の解除は Artisan 側が「再開」と解釈して残りを作り始めてしまう）

### 何を作るか

製作手帳の収集品欄と**同じ順**で候補を並べる（名前順・レベル順では手帳と見比べられない）。

1. **製作するジョブ**を選ぶ
2. レベル帯を選ぶ（帯が 2 つ以上あるときだけボタンが出る。50-60 / 61-70 / 71-80 / 81-90 / 91-100。**50-60 は Lv60 を含む**）
3. 収集品を選ぶ

橙貨はジョブごとに 1 件なのでジョブを決めれば自動で決まる。
紫貨はレベル帯ごとに複数あり、生むスクリップ量も違うので選ぶ必要がある。

**収集品を選ぶと設定が自動で変わる**

- 「製作して稼ぐ」が ON
- どこまで交換するかが「交換できる限り」
- 交換リストの全行の個数が 0（1 個ずつ窓口へ往復しないため）

製作の選択肢は「**製作で稼げる通貨**」のプリセットにだけ出る。
トームストーンのプリセットには出ない。

### 止まり方

| 条件 | 動作 |
|---|---|
| 何も動かない周が 2 回続く | 打ち切る |
| 素材が尽きた | **チャットへ通知**して停止（自分にだけ見える） |
| 呼び鈴が近くに無い | **30 秒後に自動で再試行** |
| 利用者が止めた | 利用者が操作するまで走り出さない |

暴走への歯止めは 5000 周。

## 7. リテイナーからの取り出し

製作の素材をリテイナーから引き出す。
Artisan の「Restock Inventory From Retainers」と同じことを自前で行う
（あちらは画面のボタンからしか呼べず、IPC が無いため）。

### AutoRetainer との関係

**AutoRetainer には何も依頼しない。やるのは競合の回避だけ。**

- `SetSuppressed` で**新規開始だけ**を止める。実行中の処理は中断しない
- **自分が立てた抑制だけを解除する**（他プラグインや利用者が立てたものは触らない）
- 未導入でも動く

**Allagan Tools には依存しない。** リテイナーを開けば持ち物は直接読める。

### リテイナーの持ち物を覚える

覚えていないと、1 種類の素材ごとに全員を開閉することになる
（実測で黒麦 1 種類のために 4 人で 14 秒）。

- **自分で開いたときだけでなく、人が手で開いたときも控える**
- **3 日より古い記録は当てにしない**。ただし**1 人ずつ**判定する
  （1 人だけ古いせいで全員ぶんが使えなくなるのを避ける）
- 「覚えたものを消す」操作もある

**行く前に在庫を見立てる**

| 判定 | 意味 |
|---|---|
| ある | 持っている人がいる。行く価値がある |
| 尽きた | **全員**の持ち物を覚えていて、どこにも無い。行かずに止める |
| 分からない | 覚えていない相手が 1 人でもいる。**行って確かめる** |

「知らないこと」を「無い」と決めつけない。

### 呼び鈴の場所を覚える

遠い呼び鈴はゲームのオブジェクト一覧に載らないため、場所が分からないと向かえない。

- 街だけでなく**宿屋や地下工房も同じ仕組み**で覚える
- **キャラクターでは分けない**（呼び鈴はワールドの設置物なので誰から見ても同じ）
- **当てが外れたら忘れる**（ハウジングの動かせる調度品を覚えても、1 度歩くだけで済む）

**制約**: 呼び鈴が近くに無いと素材を取り出せない。ただし 30 秒後に自動で再試行する。
納品窓口のそばには呼び鈴があるため、一度納品まで進めば以後は自力で回る。

## 8. AutoDuty との連携

### 周回の一時停止と再開

**Stop ではなく Pause を使う。** Stop は AutoDuty の内部処理を畳むため、
ダンジョン後に積まれたループ間処理（リテイナー・GC 納品・修理）の予約ごと消えてしまう。

**周回の維持**（設定 ON が既定）: AutoDuty が周回を終えて停止したら、こちらから再開させる。

- 手動停止と周回完了を区別する
- **再開したのに 20 秒以内に止まったのが 2 回続いたら諦める**
  （利用者が手で止めたのを押し返さないため）
- 渡せていない交換があるあいだは再開を待つが、上限 3 分

### AutoDuty 側の設定点検

画面に 8 項目のチェックリストが出る。多くは自動で直せる。

| 項目 | 期待値 | 理由 |
|---|---|---|
| 周回数 | **1** | 1 周ごとに交換の機会ができる |
| ループ間処理 | 有効 | 無効だと何も実行されない |
| **Run on last Loop** | **有効** | **ここが要。**無効だと 1 周設定で一度も実行されない |
| リテイナー連携 | 有効 | ダンジョン後にリテイナーへアクセス |
| リテイナーへ向かう猶予 | 0 より大（推奨 300） | 0 のままだとリテイナーへ行かない |
| GC 納品 | 有効 | 軍票交換と希少品の納品 |
| コンテンツから自動で出る | 有効 | 無効だとダンジョン内で停止し交換に入れない |
| 終了時の動作 | Do_Nothing（**自動で直さない**） | ログアウト設定だと毎周回それが走る |

### 版の制限

**AutoDuty 0.0.0.340 以上**が必要（設定で変更可、空にすると制限しない）。
古い版では設定の読み書きができず、ループ間処理の設定を確かめられないため、
この版を下回るあいだは**戦闘の自動周回を使わせない**。

## 9. FATE 自動周回

### 9-1. 何をするか

1. 周回するマップの**一覧の上から順に**テレポートする
2. そのマップで狙える FATE を選ぶ
3. マウントに乗り、飛べるなら飛んで向かう
4. FATE の中心（または敵）の地上へ**斜めに降りて**着地する
5. BossMod Reborn のプリセットで戦う
6. 達成度 **100% を見た瞬間**に離脱し、次の FATE へ
7. マップに狙える FATE が無くなったら、次のマップへ

### 9-2. 狙う FATE の選び方

次の条件を**すべて**満たすものだけが候補になる（`FateScanner.IsEligible`）。

| 条件 | 既定 | 設定名 |
|---|---|---|
| 進行中である（Running） | — | — |
| 達成度が上限以下 | **90%** 以下 | 残り時間・達成度 |
| 残り時間が下限以上 | **120 秒** 以上 | 同上 |
| 座標が取れている | — | — |
| 見送り中でない | — | （辿り着けなかった FATE は 5 分間見送る） |
| 納品 FATE を狙う設定か | 狙う | 納品 FATE も対象にする |
| レベル差が範囲内 | **無効** | レベルで絞る（既定オフ） |

候補が複数あるときの**優先順位**（`DefaultSortOrder`）は

1. **ボーナス付き**を優先
2. **達成度が高い**ものを優先（早く終わる）
3. **残り時間が短い**ものを優先（逃すともったいない）
4. **近い**ものを優先

### 9-3. パーティ同行

「パーティの仲間と同じ FATE を狙う」を入れると、**仲間が入っている FATE が
候補にあれば、そちらを優先**する。

- **同期はしない。** 仲間の座標を見て「どの FATE の円にいるか」を判定するだけ
- したがって**相手が同じプラグインを使っている必要は無い**
- 条件（残り時間・達成度・見送り中）は曲げない。仲間の FATE が条件から
  外れているなら、ふつうに選び直す
- 何人もいれば、いちばん多く集まっている FATE を採る

### 9-4. 移動と着地

- 遠い FATE へは**マウントに乗ってから**向かう（20m 以上離れていれば乗る）
- 飛べるエリアなら**飛んで**向かう。離陸は vnavmesh に任せる
- **飛行の高度上限を超えない。** 上限はマップごとに違う（実測で
  中央ラノシア 90 / 高地ラノシア 31 / 南ザナラーン 58）。
  飛んで届いた高さを覚え、それより上を目指さない
- 着地は**外周ではなく中心（または敵）の地上**。真上から垂直に落ちるのではなく、
  **斜めに高度を下げながら**近づく
- 中心が湖や崖の上なら、**立てる場所へ寄せてから**向かう

### 9-5. 詰まったときの脱出

段階を踏んで抜ける。

1. **経路をなぞらせて引き直す**（追従の許容値を詰める）＋ジャンプ
2. **迂回**（進行方向に避ける球を置いて経路を引き直す。半径を広げながら 2 回）
3. **直接移動**（経路探索を通さず、立てる場所へ直接向かう。4 回まで）
4. **帰還**（それでも駄目なら、ホームポイントへ戻って脱出する）

どの段階でも抜けられなければ、その FATE は **5 分間見送って**次へ進む。

見張りは**段階を問わず**働く。移動中・着地中・敵への接近中に
**25 秒のあいだ 3m も動かなければ**、地形に挟まったとみなして脱出へ進む。

### 9-6. 戦闘

戦闘は **BossMod Reborn に任せる**。専用のプリセット
`AutoCollector FATE` を自動で作り、有効にする。

- **BMR の AI（`/bmrai`）は使わない。** AI を入れるとプリセットが
  上書きされ、技もレベルシンクも動かなくなる
- 狙う・撃つ・寄る・シンクする、のすべてをプリセットの中で完結させる
- **FATE の敵は自分から攻撃する。それ以外は自分から絡まない。
  ただし攻撃を受けたら反撃する**（`AutoTarget` の設定で表現）
- 敵が 15m より遠ければ、こちらから歩いて近づく
- **納品 FATE の納品は BMR に任せる。** 10 個溜まると BMR が
  納品 NPC へ向かうので、こちらは手を引く

### 9-7. その他の挙動

| 場面 | 動作 |
|---|---|
| 戦闘不能 | 既定は**レイズを待つ**。15 秒待って来なければ街へ戻る（設定で変更可） |
| バディ | 残り時間が 300 秒を切ったら呼び直す（既定 ON）。未所持なら呼ばない |
| 達成度 100% | **待たずに即離脱**。その場に留まらない |
| 納品 FATE の報酬 | 100% でもすぐ報酬が入らないため、**最大 90 秒はマップを離れない** |

## 11. 安全装置

### 11-1. 交換を始めてよいか

**不変条件：Duty 中は絶対に交換を始めない。**
AutoDuty を止めるのは Duty の外に出てから。

次の状況では交換を始めない。理由は 2 種類に分かれ、画面での見せ方も変わる。

| 状況 | 種類 |
|---|---|
| プレイヤーが利用できない／操作できない | 人の対応が要る |
| 戦闘不能 | 人の対応が要る |
| 画面の読み込み中 | 待てば解消 |
| **コンテンツに参加中** | 待てば解消 |
| 戦闘中 | 待てば解消 |
| エリア移動中 | 待てば解消 |
| カットシーン中 | 待てば解消 |
| 詠唱中／動作中／他の操作中 | 待てば解消 |
| トレード中 | 待てば解消 |

### 11-2. FATE 周回を続けてよいか

FATE 周回には**別の判定**を使う。
**戦闘中・詠唱中・動作中・戦闘不能は弾かない**（周回では正常な状態だから）。

弾くのは次だけ。

- プレイヤーが利用できない／画面の読み込み中
- **コンテンツに参加中**
- エリア移動中／**カットシーン中**／**トレード中**
- 操作できない状態

### 11-3. 緊急停止

`/autocollector stop` または各画面の「止める」で、次の順に止める。

1. 束ねている側（目標つき周回）から先に止める
   — でないと交換を止めた直後に製作や取り出しが始まる
2. 子の処理（リテイナー取り出し・製作）も直接止める
   — 製作計画タブから手で始めたものは、束ねている側からは止まらない
3. 交換を中止し、握った制御を解放する

FATE 周回も、周回中かどうかに関わらず止める。
止めたあと 20 秒は、あとから積まれた経路を捨て続ける
（経路探索は取り消せないため、完了した結果が勝手に積まれる）。

### 11-4. セルフチェック

起動時・ゲームバージョンの差分を検知したとき・交換開始直前に走る。
**1 つでも「失敗」があれば交換を開始しない。**

| 検査 | 落ちる条件 |
|---|---|
| ゲームバージョン | 変わっていたら**警告**（最初の交換は手動で確認を） |
| ゲームデータの改変 | 検出したら警告 |
| トームストーンの解決 | **1 件も解決できなければ失敗** |
| 週上限の整合 | 不整合なら警告 |
| 通貨の読み取り | **所持数が取れなければ失敗** |
| 連携プラグイン | 版が変わっていたら警告（IPC が変わっている可能性） |

## 12. 主な設定（FATE 以外）

| 設定 | 既定 | 意味 |
|---|---|---|

## 13. 記録（ログ）

**常に記録する。** 設定で切ることはできない。

```
%APPDATA%\XIVLauncher\pluginConfigs\AutoCollector\AutoCollector_yyyyMMdd_HHmmss.log
```

- 周回中は、どの段階で何を判断したかを逐一記録する

## 14. 既知の制約

### 設定がキャラクター間で共有される

設定ファイルは **1 つだけ**（`DefaultConfig.json`）。複数のキャラクターで
同時に動かすと、後から保存したキャラの設定が他を上書きする。
**キャラクターごとに違う設定にはできない。**

### 周回マップの巡回順

**一覧の上から順**に回る。開始時は必ず先頭のマップへ向かうため、
別のマップで開始すると、まず先頭へテレポートする。

交換から戻ったときだけは、**離れたマップから再開**する
（巡回の順番ではなく中断の復帰なので）。

### 他プラグインへの影響

詰まったときに vnavmesh の経路追従の許容値を一時的に変える。
**これは vnavmesh 全体の設定**なので、変えている間は他のプラグインの
移動にも影響する。移動が終われば既定値へ戻す。
