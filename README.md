# Auto Collector

FINAL FANTASY XIV / Dalamud 向けプラグイン。

通貨が指定した閾値へ到達したら、実行中の自動処理を安全に停止し、交換所へ移動して指定アイテムへ交換し、元の処理へ復帰します。通貨が上限に達して周回や納品が止まるのを防ぐことが目的です。

> **開発中です。** 現在は交換の中核部分（ゲームデータからの交換先解決、ショップの読み取り・照合、交換の実行と検証）まで動作します。移動・自動起動はこれからです。

---

## 特徴

### ゲームデータから解決する

交換先の NPC・ショップ・コスト・座標をコードに埋め込まず、すべてゲームのデータから実行時に解決します。新しいパッチで交換品が追加されても、プラグイン側の更新なしに扱えることを目指しています。

トームストーンは ItemId を直接持たず `Tomestones` シートのスロット番号で参照するため、パッチで現行トームストーンが入れ替わっても設定を書き換える必要がありません。

### 誤った交換をしない

通貨の消費は取り消せないため、判断材料が 1 つでも欠けたら実行しない設計にしています。

- 交換前に、開いているショップがどれかを画面の内容から特定する
- 対象アイテムの ID とコストが、ゲームデータと一致することを確認する
- 交換後に「通貨が減った」かつ「アイテムが増えた」ことを所持数から検証する
- 結果が確認できなかった場合、自動で再送しない（二重購入の防止）

同じアイテムが複数のショップに別の値段で載っていることがあるため、ID だけでの照合はしません。

### 外部プラグインを強制停止しない

AutoDuty / AutoRetainer / vnavmesh / Lifestream と連携しますが、いずれも必須ではありません。未導入の場合は該当機能のみ無効になります。

AutoRetainer に対しては、実行中のタスクを中断せず新規開始のみを抑制する協調的な方法を使います。

## 対応予定の交換

| 通貨 | 状態 |
|---|---|
| アラガントームストーン（数理・記憶・詩学） | 実装済み |
| 軍票（グランドカンパニー） | 予定 |
| ギャザラー／クラフタースクリップ（紫貨・橙貨） | 予定 |
| その他の交換型通貨（バイカラージェム、トロフィークリスタル等） | 予定 |

詳細は [`docs/01_交換対応範囲.md`](docs/01_交換対応範囲.md) を参照してください。

## 動作環境

- FINAL FANTASY XIV

- .NET 10

## ビルド

```
dotnet build -c Debug
```

Debug ビルドは `C:\DevPlugins\AutoCollector\` へ出力されます。Dalamud の設定で Dev Plugin Locations に **DLL の絶対パス**を登録してください（フォルダではありません）。

---

## コマンド

| コマンド | 動作 |
|---|---|
| `/autocollector` | ウィンドウの開閉 |
| `/acc` | 同上（他プラグインと衝突する場合は設定で無効化できます） |
| `/autocollector stop` | 緊急停止 |
| `/autocollector check` | セルフチェックの実行 |

---

## 設定ファイル

`atkvalue_layout.json` には、交換ショップ画面から値を読み取る位置を記録しています。ゲームや Dalamud の更新でこの配置がずれた場合、この数値を書き換えるだけで復旧できます。

ずれた場合は読み取りが失敗するか ID の照合が一致しなくなって安全に停止するため、誤ったアイテムを購入することはありません。
